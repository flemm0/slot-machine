
# Slot Machine – React + Vite

This project is a simple slot machine game built with React and Vite, featuring hot module replacement and minimal setup.

## Features

- Interactive slot machine UI
- Built with React for fast development
- Powered by Vite for instant reloads

## Credits

Some of the code and inspiration for this project comes from this [CodePen slot machine demo](https://codepen.io/josfabre).

## Getting Started

1. Install dependencies:
	```
	npm install
	```
2. Start the development server:
	```
	npm run dev
	```
